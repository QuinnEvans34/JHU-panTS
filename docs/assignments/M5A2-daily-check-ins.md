# M5A2: Daily Check-Ins

**Due:** Thursday 11:59pm (available until Jul 30 11:59pm) · **Points:** 10 · **Submit:** website URL or file upload (final `standup-log.md` in the repo)

## Overview
Consistent, honest daily reflection is a professional habit — not busywork. `standup-log.md` is a running record of how you worked, what slowed you down, and how you responded. It lives in the repo, is reviewed during 1-on-1 check-ins, and is referenced in the final presentation. Treat it as a document you'd be comfortable showing an employer.

## Instructions
Update `standup-log.md` at the **end of every weekday (Mon–Fri)**. Each entry brief and honest — 3–5 sentences. Write what actually happened, not what you wish you'd done.

### Standard daily entry format
```
## [Week X — Day] — [Date]
**Worked on:** What did you actually work on today?
**Up next:** What are you working on in the next session?
**Blockers:** Any challenges or blockers? If none, write "None."
```

### 1-on-1 Retrospective entry (Weeks 1, 3, 5 only — replaces one standard entry)
Written after the instructor check-in that day.
```
## [Week X — 1-on-1 Retrospective] — [Date]
**What we discussed:** Key topics covered in the check-in.
**Feedback received:** Specific feedback / direction from the instructor.
**Action items:** What you'll do differently or prioritize as a result.
**Reflection:** 1–2 sentences — anything that surprised you or that you want to think more about.
```

## File location & format
`standup-log.md` lives in the root `docs/` folder. Entries are added **chronologically — do not edit or delete previous entries.** The log grows across all 5 weeks into a complete record.
